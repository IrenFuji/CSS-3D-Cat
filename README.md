# 3D Cat Drawing 🐱 

## Goal

Create a cute, animated, and slightly 3D-styled cat face using pure HTML and CSS.  
This project is a fun FE exercise focused on layering, and visual styling.

---

## Tech Stack

- **HTML5** – Structure and layout
- **CSS3** – Styling, gradients, shadows, and 3D effects
- **No JavaScript** – 100% CSS-powered

---

## Preview

Feel free to fork or extend this with animations like blinking, floating effects, or more!
